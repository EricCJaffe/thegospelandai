# AGENTS.md — The Gospel and AI (Codex)

Read `CLAUDE.md` in this directory first. It is the substance, and everything
in it applies here; this file exists because Codex looks for this name.

The four things most likely to matter before you touch anything:

1. **This repository deploys on push to `main`.** The Vercel project is
   git-connected with no staging, so a push publishes to thegospelandai.com.
   Confirm the branch and account for every commit first.
2. **Stay inside this repository.** Several agent sessions run on this box at
   once, one per project. `.claude/settings.local.json` holds the deny list
   and is generated by `scope-projects`; do not hand-edit it.
3. **US English, always** — code, UI strings, docs, commits, and anything the
   site renders.
4. **The service-role key must never reach the browser.** Privileged work
   belongs in `api/`, which runs server-side.

`npm test` is Node's own runner and takes under a second. Run it before you
push, because on this repo pushing is publishing.
