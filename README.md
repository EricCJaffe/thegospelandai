# The Gospel and AI

Landing page for *Anchored in the Storm* — a Christian guide to thriving in the age of AI, by Eric Jaffe.

🌐 **thegospelandai.com**

## About

A static landing site for the book, including the table of contents, author bio, AI companion preview, small-group resources, and an email capture for launch updates.

## Development

This is a static site — no build step required. Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Deployed on [Vercel](https://vercel.com). Pushes to `main` deploy automatically.
